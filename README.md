# Credit Card Financial Dashboard | SQL & Power BI

## Project Overview
This project analyses credit card customer and transaction data using SQL and Microsoft Power BI. It focuses on understanding customer segments, transaction trends, revenue-related metrics, and key financial indicators through interactive dashboards.

## Objectives
- Analyse credit card transactions and customer demographics.
- Track key performance indicators (KPIs) and quarterly trends.
- Compare performance across card categories, customer occupations, income groups, and expenditure types.
- Present findings through interactive Power BI reports.

## Tools and Technologies
- **PostgreSQL:** Database creation, table management, and CSV data loading.
- **SQL:** Data retrieval and preparation.
- **Microsoft Power BI:** Dashboard development and visualisation.
- **DAX:** Calculated columns and measures.
- **CSV:** Source data files.

## Project Workflow
1. Imported customer and credit card transaction datasets into PostgreSQL.
2. Created separate tables for customer and transaction-related information.
3. Connected the data to Power BI for analysis and reporting.
4. Created DAX calculations for customer segmentation and financial KPIs.
5. Developed interactive dashboards to explore customer and transaction performance.

## Dashboards

### 1. Credit Card Customer Report
Analyses customer demographics, age groups, income groups, occupations, geographical distribution, and revenue-related metrics.

### 2. Credit Card Transaction Report
Examines transaction amounts, transaction counts, interest earned, expenditure categories, card categories, and quarterly trends.
